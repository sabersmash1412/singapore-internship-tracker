# Listing quality audit — 24 September 2026

Reviewed a purposive sample of 40 previously published listings across all 11 employers with matching roles. The sample deliberately includes ambiguous titles and older intakes; it is not a random estimate of overall accuracy. DBS had no matching Singapore technical internships.

## Method and findings

- Refetched all 12 official feeds: all completed successfully. Matched sampled IDs to current source records and reviewed location, internship status, role descriptions and advertised periods.
- Requested all 40 official posting URLs: all returned HTTP 200, one after retrying an interrupted response. This establishes reachability, not that an application form accepts submissions; some sites serve JavaScript shells. No applications were submitted.
- Removed five confirmed scope errors: one HR role, one commercial-support role and three administrative project-management roles whose AI/data team names caused false positives.
- The fresh collection added three matching roles. After corrections, 349 retained listings comprise 335 current/undated listings and 14 older advertised periods. Older periods remain in downloads and a collapsed README table; their source availability is not changed.
- Scope includes business analytics and technology product/design roles, not only coding internships. Title-based category labels are approximate. Some explicit single-month starts and additional description dates are not extracted; inspect employer details.
- GovTech's [official programme page](https://www.tech.gov.sg/careers/students-and-graduates/internships/) states applications close on **30 September 2026 at 12pm**. The catalogue's unfilled flag is not an application-window check. This remains a collection limitation.

## GitHub Actions verification

The [latest existing test run](https://github.com/sabersmash1412/singapore-internship-tracker/actions/runs/35946797717) passed for the expanded implementation. The [earlier manual refresh](https://github.com/sabersmash1412/singapore-internship-tracker/actions/runs/35945391839) succeeded before that expansion. No scheduled executions appeared in the available recent run history at audit time. Therefore the 12-board collection is verified locally, but scheduled GitHub-hosted collection remains unverified. The workflow is configured for minute 17 and 47 each hour; configuration alone is not evidence of execution.
